공룡 화석 발굴 체험

1. 기획 의도
VR 환경에서 플레이어가 직접 고고학자가 되어 공룡 화석을 발굴하고 복원하는 체험형 콘텐츠를 제작한다. 다양한 도구를 활용한 상호작용을 통해 발굴 과정의 재미와 공룡 골격을 완성하는 성취감을 제공하고자 한다.

2. 콘텐츠 개요
플레이어는 화석 발굴 현장에서 망치와 붓을 사용해 돌과 흙 속에 숨겨진 공룡 화석을 발견한다. 발굴한 화석을 깨끗하게 정리한 후 전시대의 알맞은 위치에 배치하여 하나의 공룡 골격을 완성한다.

3. 플레이 진행 순서
-망치로 돌을 깨서 화석 발견하기
-붓으로 화석에 묻은 흙과 모래 제거하기
-발굴한 화석을 전시대로 옮기기
-화석을 알맞은 위치에 배치하여 공룡 골격 조립하기
-완성된 공룡 골격 감상하기

4. 주요 구현 기능
-VR 컨트롤러를 활용한 오브젝트 잡기 및 이동
-망치질과 붓질을 통한 단계별 화석 발굴
-화석의 위치 판정 및 스냅 기능
-골격 완성 시 조명, 효과음 및 파티클 연출

5. 제작범위
공룡 한 종류, 뼈 화석 4~6개, 발굴 도구(망치, 붓)
